# KeenKeeper - Keep Your Friendship Alive

## Description

KeenKeeper is a friendship management tool that helps users stay connected with their contacts.
It tracks interactions like calls, texts, and video chats in a timeline view.
Users can quickly log activities and see their communication history in one place.
It also provides analytics to show how often each type of interaction happens.
Overall, it helps users maintain stronger and more consistent relationships.

## Key features of this project

- It tracks interactions like calls, texts, and video chats in a timeline view.
- Users can quickly log activities and see their communication history in one place.
- provides analytics to show how often each type of interaction happens.

## Technologies to use

- React.js
- React Router DOM
- Tailwind CSS + Daisy UI
- Recharts
